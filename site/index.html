01 · 功能

六件事，把无线环境讲清楚

  1. 实时扫描一键巡视周围的电波

    调用系统原生命令扫描周围网络，可选每 5 秒自动刷新。不装驱动、不要管理员权限，打开就能用——系统能看到的网络，它都能列出来。

  2. 信号排序最强的信号排在最前面

    网络按 RSSI 降序排列，SSID、BSSID、信道、频率、频段、安全类型一行看全，当前已连接的网络高亮标出。挑网络不再靠猜格数。

  3. 信道拥堵分析看见空气里的交通状况

    按 2.4GHz / 5GHz / 6GHz 频段分组的信道负载柱状图，并计入 2.4GHz 相邻信道的重叠干扰。路由器该落在哪条信道，看一眼柱子就有答案。

  4. RSSI 历史曲线记下信号的每一次起伏

    前端按 BSSID 持续记录信号历史，为选中网络绘制 SVG 曲线。走到哪里信号开始衰减、哪个时段开始抖动，曲线替你记着。

  5. 智能建议结论给你，理由也给你

    基于确定性规则算法输出最多三条建议：连哪个网络、2.4GHz 和 5GHz 各切到哪条信道。每条建议附带评分与依据，可复现、可解释。

  6. 应用内连接从分析到连接，不出这扇窗

    看准目标后直接在弹窗里输入密码发起连接；源码构建的 Linux 版本支持企业网络用户名。底层调用系统命令完成。配合系统托盘常驻，关窗不退出。

02 · 原则

五条底线，写在代码里

  1. 01
    数据不出设备 扫描结果只活在内存里。应用不发起任何网络请求，没有遥测，也没有统计埋点。
  2. 02
    规则可解释 建议来自确定性规则算法，不是 AI 黑盒。同样的无线环境，永远得到同样的结论。
  3. 03
    借系统的眼睛 扫描与连接全部调用各平台自带命令——airport、netsh、nmcli——不绕过系统权限模型。
  4. 04
    轻得像个仪表 Tauri 2 外壳复用系统 WebView，不捆绑浏览器内核；前端零框架，图表是手写 SVG。
  5. 05
    开源可审计 MIT 许可证，全部源码公开在 GitHub。上面四条不必信宣传，可以亲自读代码验证。

04 · 常见问题

下载之前，你大概想问

和系统自带的 WiFi 列表有什么不同？
系统列表只告诉你"有哪些网络"；WiFi 分析器告诉你哪个值得连、哪条信道更空，以及信号随时间如何变化。
建议是 AI 生成的吗？
不是。全部建议来自本地确定性规则算法，不调用任何模型或外部 API，结果可复现、可解释。
我的扫描数据会上传吗？
不会。应用不发起任何网络请求，扫描结果只保存在内存中，关掉应用就消失。
它怎么拿到 WiFi 信息？
调用各平台自带命令：macOS 用 airport（新系统回退 system_profiler），Windows 用 netsh，Linux 用 nmcli（失败时回退 iw）。
Linux 有安装包吗？
目前没有官方 Linux 发布包。代码里保留了 Linux 扫描与连接实现，熟悉 Tauri/Rust 环境的用户可以从源码构建。
免费吗？
免费且开源，MIT 许可证。没有试用期，也没有解锁付费功能的弹窗。
Windows 提示"未知发布者"怎么办？
当前构建未签名，SmartScreen 提示属正常现象；选择"仍要运行"即可，介意的话也可以从源码自行构建。
用浏览器打开会怎样？
在非 Tauri 环境下应用自动进入 Demo 模式，用内置演示数据渲染完整界面——本页截图正是这样得来的。
