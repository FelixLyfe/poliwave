# Poliwave brand assets

`logo-source.png` is the approved Poliwave master artwork. It uses the original
product palette: dark charcoal green `#0D1B19`, forest teal `#184A3F`, and mint
`#2DD8B4`.

Production exports are generated from this file:

- `src-tauri/icons/`: macOS, Windows, Linux, and tray icons
- `public/icon.png`: application shell and browser favicon
- `site/assets/icon.png`: website favicon and footer mark

The tray icon is a transparent monochrome silhouette derived from the same
character so it remains legible as a macOS template icon.
